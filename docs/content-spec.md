# Content Spec v0.2

## 共通ルール

- 実体験と最も強い気付きを起点にする。
- 一般的な褒め言葉より、生活の動作がどう変わったかを書く。
- 惜しい点は、使用者が実際に気づいた非自明な内容だけを残す。
- サイズ確認や定期清掃など、商品カテゴリから当然に予想できる注意は原則として書かない。
- 実体験に基づく惜しい点がない場合は、無理に作らず項目自体を省略する。
- 根拠のない「一番」「必須」「必ず得する」「人気」は使わない。
- カルーセルは1ページ1メッセージに絞る。
- 事実、本人の体験、推測、試算を混ぜない。

## 楽天ROOM

目的は、購入判断を助けること。

文章は次の順序を基本とする。

1. 正直な結論
2. 本人の使用体験
3. 生活で得られた変化
4. 購入前に知るべき惜しい点

ブランドの合言葉を毎回繰り返す必要はない。プロフィールで伝える。

## Instagram

### 編集区分

- `LIFT Classic`: 本人または家族が実際に使った商品。体験、変化、惜しい点を本人情報として書く。
- `LIFT Select`: 公式情報、販売ページ、第三者レビューを調査して選んだ商品。「調査して選定」と本文で明記し、使用したような表現を禁止する。
- `LIFT Select` の惜しい点は、確認できた仕様または複数レビューで共通する傾向だけを書く。出典のない弱点を生成しない。
- 公開比率は `Classic 1 : Select 2` を上限とする。Selectが2件続いたら、次のSelectは公開待ちへ戻す。

目的は、LIFTの認知と保存したくなる理解を作ること。

カルーセルは6ページで構成する。

1. フック
2. 悩み
3. 変化
4. 正直なレビュー
5. 気付き
6. CTA

CTAページには、プロフィールの楽天ROOMへ移動した後に使う短い検索語を表示する。スマートフォンで入力しやすい1〜8文字を基本とし、商品名を正確に再現するよりも自然な語を優先する。初期商品は「排気口」「ごはん」「カッター」とする。同じ検索語に関連商品が複数並ぶことは許容するが、無関係の商品が増えた時点で検索語を見直す。

通常購入品はPR表示を付けない。商品提供、特別クーポン、投稿依頼、楽天または広告主とのイベントなどがある場合だけ、広告であることが明瞭に分かる表示を付ける。

## Threads

目的は、ひとつの気付きを会話に近い短文で伝えること。

通常購入品はPR表示を付けない。商品提供、特別クーポン、投稿依頼、楽天または広告主とのイベントなどがある場合は、本文上部に明瞭なPR表示を付ける。返信欄やツリーだけに表示しない。

すべての投稿を販売リンクへ直結させない。商品を扱わない日常の気付きには広告表示を付けない。

## 文字数の目安

- 表紙見出し: 原則2行、目安16文字
- Insight: 目安24文字
- 本文ページ: 最大120文字
- CTA: 1アクション

機械的に切り捨てず、超過時は編集確認へ回す。

## 広告表示の根拠

消費者庁「ステルスマーケティングに関するQ&A」は、「広告」「宣伝」「プロモーション」「PR」や「このサイトはアフィリエイト広告を利用しています」など、広告であることが一般消費者に明瞭になる表示例を示している。表示の文字サイズ、色、位置も明瞭さに影響する。LIFTで使う具体的な文言と位置は、媒体表示を確認して決める。
