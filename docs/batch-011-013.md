# Production Batch 04: lift-011 to lift-013

Updated: 2026-08-09

この3商品は、オーナーが通常購入して実際に使っている商品。商品ページの事実と使用体験を分けて記録する。

## lift-011: tower 食器収納シリーズ

- 購入品: お椀スタンドS、お椀スタンドL、お皿スタンド
- 商品ページ: https://item.rakuten.co.jp/roomy-garden/ymz25jan31h11/?variantId=YMZ5506-SS026-0I---1371
- 商品ページで確認した事実: 5タイプ展開。購入した3タイプは食器を立てて収納し、平積みせず取り出せる
- 使用体験: 食器ごとの保管場所を固定できた
- 惜しい点: なし
- 主訴求: 食器の住所を決める収納

## lift-012: Mirx 麦茶ポット 3.5L

- 購入タイプ: URL指定の `waterbottle-WH-m-Nw`
- 商品ページ: https://item.rakuten.co.jp/neo-lifestyle/waterbottle-copy/?variantId=waterbottle-WH-m-Nw
- 商品ページで確認した事実: 3.5L、横置き対応
- 使用体験: 大量の麦茶を一度に作れる。独特な注ぎ方を小さい子どもが楽しんでいる
- 惜しい点: 蓋が固く、閉め終わりの位置が明確でないため微調整が必要
- 主訴求: 麦茶を作り足す回数を減らす

## lift-013: キャップウォッシャー

- 購入品: Bタイプ
- 商品ページ: https://item.rakuten.co.jp/chakasho-dina/255maozijiazi/
- 商品ページで確認した事実: Bタイプは洗濯ネット付き。洗濯中の摩擦や絡まりを抑える構成
- 使用体験: キャップを型崩れさせずに洗え、他の洗濯物との摩擦も気にならない
- 惜しい点: なし
- 主訴求: 形と表面を守ったまま洗濯機へ任せる
